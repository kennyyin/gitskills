# 🗣️ 英语口语陪练 · English Speaking Coach

一个**单文件、零依赖、免安装**的英语口语练习网页工具，专为**日常口语交流**设计。

## 功能

- 🔊 **标准发音**：浏览器语音合成（TTS）朗读英文句子，支持慢速。
- 🎤 **跟读打分**：用麦克风录下你的朗读，识别后与标准句逐词对比并给出 0–100 分。
- 🟢🔴 **逐词纠错**：说对的词显示绿色，漏掉/说错的词标红，一眼看出薄弱处。
- 📚 **场景分组**：打招呼、闲聊、餐厅、问路、购物、工作等真实日常场景。
- 🔒 **隐私安全**：纯前端运行，不上传任何数据，不需要 API key。

## 使用方法

直接用浏览器打开 `index.html` 即可。

> 💡 **录音打分功能**依赖浏览器内置的语音识别，请使用**桌面版 Chrome 或 Edge**，
> 首次使用会请求麦克风权限。朗读功能在所有现代浏览器均可用。

## 快捷键

| 按键 | 功能 |
| --- | --- |
| `空格` | 播放标准发音 |
| `R` | 开始 / 停止录音跟读 |
| `←` / `→` | 上一句 / 下一句 |

## 如何添加你自己的句子

打开 `index.html`，在顶部的 `DATA` 对象里按场景增删句子即可：

```js
const DATA = {
  "我的场景": [
    { en: "Your English sentence.", zh: "对应的中文" },
  ],
};
```
