# 🗣️ 英语口语陪练 · English Speaking Coach

一个**单文件、零依赖、免安装**的英语口语练习网页工具，专为**日常口语交流**设计。

## 五大模式 + 主题切换

> 🌙 / ☀️ 右上角按钮一键切换**深色 / 浅色主题**，选择会被记住。

### 📚 练习模式
- 🔊 **标准发音**：浏览器语音合成（TTS）朗读，支持 🐢 慢速。
- 🎤 **跟读打分**：录下你的朗读，识别后与标准句逐词对比，给 0–100 分。
- 🟢🔴 **逐词纠错**：说对的词绿色，漏掉/说错的标红。
- 7 个真实场景：打招呼、闲聊、餐厅、问路、购物、工作、旅行。

### 💬 对话模式（连读整段对话）
- **6 段**日常对话：咖啡店点单、初次见面、问路、餐厅就餐、看医生、电话预约。
- **选择你扮演的角色**，对方的台词由 AI **自动朗读**，轮到你时录音跟读，逐句打分。
- 答对自动进入下一句，模拟真实双人对话节奏。
- 🔊 **整段连读**：一键按顺序朗读全部台词，**高亮当前句 + 自动滚动 + 顶部中英对照字幕条**，适合先整体听一遍再开练。
- 每句对话气泡下方也显示 IPA 音标。

### ✏️ 编辑模式（可视化自定义语料）
- **表单编辑，无需写 JSON**：直接增删/修改场景、句子、对话、角色与台词。
- 🔊 **逐句试听**：每行一个试听按钮，朗读当前英文，方便校对。
- ⠿ **拖拽排序** + ▲▼ **上下移动**：桌面可拖动手柄排序，手机用上下按钮排序。
- 🖨️ **打印 / PDF 清单**：一键生成带 IPA 音标的练习清单，用浏览器「打印」即可另存为 PDF。
- **导入 / 导出 JSON**：一键导出备份或分享，导入后检查再保存。
- 内置格式与重名校验，出错会给出明确提示；可一键**恢复默认**。
- 自定义内容保存在本机浏览器（`localStorage`），词典外的单词音标处显示「·」。

### 📒 错题本
- 练习/对话中得分低于 **70** 的句子**自动收录**。
- 可随时回看、🔊 朗读、🎤 重练；重练达标后自动移出错题本。

### 📊 进度
- 最近 **14 天**练习曲线：**柱状**显示每日练习句数，**折线**显示每日平均得分（0–100）。
- 底部汇总总练习句数、活跃天数和平均分。

## 🔤 IPA 音标
每句英文下方显示**通用美音国际音标（IPA）**，练习卡、对话气泡、错题本均可见。
音标来自内置离线词典，**无需联网**。

## 打卡统计
顶部实时显示 **连续打卡天数**、**今日练习句数**、**错题本数量**。
所有数据通过浏览器 `localStorage` **仅保存在你本机**，不上传任何服务器。

## 使用方法
直接用浏览器打开 `index.html` 即可。

> 💡 **录音打分 / 对话模式**依赖浏览器内置语音识别，请使用**桌面版 Chrome 或 Edge**，
> 首次使用会请求麦克风权限。朗读功能在所有现代浏览器均可用。

## 快捷键（练习模式）
| 按键 | 功能 |
| --- | --- |
| `空格` | 播放标准发音 |
| `R` | 开始 / 停止录音跟读 |
| `←` / `→` | 上一句 / 下一句 |

## 自定义内容
两种方式：
1. **页面内编辑（推荐）**：进入「✏️ 编辑」模式，直接修改 JSON 并保存。
2. **改源码**：编辑 `index.html` 顶部的 `DEFAULT_DATA` / `DEFAULT_DIALOGUES`。

```jsonc
// 练习场景
{ "我的场景": [ { "en": "Your sentence.", "zh": "中文" } ] }
// 对话剧本（role 为 0 或 1）
{ "我的对话": { "roles": ["角色A", "角色B"], "turns": [ { "role": 0, "en": "Hi.", "zh": "嗨。" } ] } }
```

## 隐私
纯前端运行，不需要 API key，不联网，数据不离开你的浏览器。
随时可点页脚「清空本地数据」重置打卡与错题本（自定义语料不受影响）。
